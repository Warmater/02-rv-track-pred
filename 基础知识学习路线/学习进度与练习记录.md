## 4. 卡点怎么处理

| 表现 | 优先回看 |
| --- | --- |
| 张量维度总出错 | 核对输入输出、轴含义和矩阵维度，按需查工具文档 |
| 概率、分数、方差混淆 | 不确定性章节及资料页的概率补充主题 |
| 雷达点投不到图像目标附近 | 01 的坐标、时间、深度和图像变换 |
| 轨迹总换 ID | 04 的门控、关联代价与生命周期 |
| 预测时间点对不上 | 05 的采样间隔与输出时刻 |
| 论文看完说不出做了什么 | 07 的六个阅读问题 |
