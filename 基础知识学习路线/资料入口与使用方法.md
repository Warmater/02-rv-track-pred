这套章节本身就是第一轮学习材料。下面的资料用于查例子、补细节和进入真实数据，不要求全部通读。尽量沿一条主线学，不同时打开多套课程。

## 2. 遇到具体问题时再补的知识

不单独安排编程、数学和概率入门阶段。按当前模块的实际需要补充：

- 坐标对齐：旋转矩阵、齐次变换、变换组合与逆变换。
- 滤波与关联：多元高斯、协方差、线性方程求解、马氏距离。
- 非线性观测：雅可比矩阵、局部线性化与 EKF。
- 不确定性评估：似然、置信区间、概率校准与采样。
- 模型实现：张量维度、自动求导和数值稳定性。

以能解释公式、核对假设并检查程序为标准，不需要重新通读整套基础教材。

## 4. 查资料时的顺序

1. 先明确一个具体问题，例如“我的坐标变换方向是否反了”。
2. 回看本章对应定义和示例。
3. 查官方文档或数据说明中的同一概念。
4. 写一个最小数值例子验证理解。
5. 记录自己确认的定义、约定和来源。

遇到英文时，先查本文件夹的[术语表](术语与符号速查.md)。翻译可以帮助理解文字，但公式里的坐标系、维度和条件需要自己核对。
