| 词 | 含义 | 章节 |
| --- | --- | --- |
| Intrinsics，内参 | 相机焦距、主点等内部成像参数 | 01 |
| Extrinsics，外参 | 不同坐标系之间的旋转和平移 | 01 |

| Query，查询 | 用于读取特征或表达候选目标的向量 | 02、03 |

## 4. 公式符号

符号可能在不同上下文中复用，阅读时先看定义。

| 符号 | 这些章节中的常见含义 |
| --- | --- |
| p、v、a | 位置、速度、加速度向量 |
| s | 目标状态向量 |
| z | 观测向量；坐标中的小写 z 也可能表示高度 |
| Δt | 两次采样的时间间隔 |
| T | 未来步数；带坐标下标的 T 也可能是齐次变换矩阵 |
| R | 几何章节为旋转矩阵；滤波章节为观测噪声协方差 |
| P、Q | 状态协方差、过程噪声协方差 |
| F、H | 状态转移矩阵、观测矩阵 |
| K | 滤波章节为卡尔曼增益；预测章节为候选轨迹数量 |
| μ、σ² | 均值、方差 |
| πₖ | 第 k 条候选轨迹的模式概率 |
| θ | 几何中可能是角度；机器学习中可能是模型参数 |
| `⊤`、`−1` | 转置、矩阵逆 |
| `‖·‖₂` | 欧氏长度 |
| `^`（帽子） | 表示估计值，如 `x̂` |
