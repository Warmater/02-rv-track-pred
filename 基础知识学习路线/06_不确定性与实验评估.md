# 06｜不确定性、鲁棒性与公平实验

[返回总目录](README.md) · 前一章：[轨迹预测](05_轨迹预测.md) · 下一章：[项目实践](07_项目实践与论文阅读.md)

**前置要求：概率、跟踪协方差、ADE/FDE。**  
**本章目标：能说清“好在哪里、证据是什么、还有什么没有被证明”。**

## 1. 四种可靠性量不能混在一起

| 量 | 回答的问题 | 不能直接代替什么 |
| --- | --- | --- |
| 观测质量 | 当前图像或雷达信息是否可靠？ | 目标存在概率 |
| 目标存在性 | 这里是否真的有目标？ | 位置误差大小 |
| 状态协方差 | 当前位置和速度估计可能偏多少？ | 各种未来行为的概率 |
| 轨迹模式概率 | 哪一种未来更可能？ | 该轨迹周围的完整空间分布 |

模型分数高，不代表几何误差必然小。正确的类别也可能配上错误的位置。

## 2. 不确定性怎样随预测增长

在简单线性传播下，可以把当前状态协方差传到未来位置：

$$
\mathbf p(\tau)=A(\tau)\mathbf s,\quad
A(\tau)=
\begin{bmatrix}
1&0&\tau&0\\
0&1&0&\tau
\end{bmatrix}
$$

$$
P_p(\tau)=A(\tau)PA(\tau)^\top
$$

这只传播当前状态的不确定性。若未来运动有额外过程噪声，还要增加其传播贡献。

例如一维速度标准差为 1 米/秒，仅速度不确定性在 3 秒外推中就贡献 9 平方米的位置方差。存在位置–速度相关性时还要计入交叉项。

这帮助理解为什么“当前速度估计差一点”会影响未来。真实多模态预测比这个线性例子复杂得多。

## 3. 校准：说有多大把握，实际就应接近多大把握

如果一批预测区域都声称覆盖概率为 90%，那么大量可比样本中，真实位置落入区域的比例应接近 90%。小样本不会恰好等于 90%，还要考虑统计波动。

覆盖率也不能单独使用：把区域画得特别大容易覆盖，但预测信息量很低。因此应同时看区域大小、误差和覆盖率。

NLL 是负对数似然，要求模型给真实结果分配了明确概率或概率密度。只有 K 条确定轨迹与权重时，不能不定义位置分布就声称计算了完整连续轨迹的高斯 NLL。

## 4. 鲁棒性与长尾场景

鲁棒性是条件变差时性能还能保持多少。长尾指较少出现的场景或类别，不等于所有误差大的样本。

项目可分别观察夜间、遮挡、远距离、稀疏回波和密集切入。真实场景标签和人为扰动实验应分开报告：给图像加暗并不能完全代表真实夜间驾驶。

测试集上的失败可以用于分析，但不能把测试样本加入训练再继续把该测试集当作未见数据。

## 5. 指标按任务选

| 环节 | 入门先看 | 进一步学习 |
| --- | --- | --- |
| 检测 | 漏检、虚警、位置误差 | 按数据集协议计算 AP/mAP 等 |
| 跟踪 | ID 切换、轨迹中断、速度误差 | 适用的 MOTA/AMOTA 等完整指标 |
| 预测 | ADE、FDE、固定 K 的最小误差 | Miss Rate、概率相关指标 |
| 可靠性 | 误差与分数是否对应 | 校准、覆盖率、适当概率模型下的 NLL |
| 工程 | 一帧耗时、内存、是否稳定运行 | 明确硬件和统计口径的吞吐与延迟 |

Precision（精确率）强调报出来的目标有多少正确；Recall（召回率）强调真实目标中有多少被找到。AP 汇总不同阈值下的精确率–召回率表现，具体匹配规则仍依协议而定。

ID Switch 计数也依赖评测器的匹配和时间规则，不能把自己临时写的计数直接当作官方结果。

## 6. 怎样设计一个能解释的对照

假设研究问题是“加入径向速度约束能否减少遮挡后身份切换”：

1. 保持检测输入、数据划分、轨迹管理规则和评测器一致。
2. 基线不使用该约束，实验组使用该约束。
3. 除整体指标外，单独报告遮挡子集及样本量。
4. 查看是否以更多漏跟踪为代价减少了 ID 切换。
5. 记录运行配置、随机种子和失败案例。

消融实验是去掉或替换某个组件来检查其作用。一次同时更换检测器、关联方法和预测器，即使结果变好，也难判断改进来自哪里。

## 7. 样本量与统计波动

某子集只有 3 个片段时，不能因为一次结果很好就认为普遍有效。记录样本数；对于相关的连续帧，估计区间时应考虑按序列或场景重采样，不能简单假装每帧都独立。

结果有随机性时可记录多个种子的均值与波动。不要在结果出来之后只挑有利子集报告。

## 8. 练习与过关

1. 候选数量 K 从 1 改成 20，minADE 下降，能否直接说模型预测能力增强？参考：不能，评测预算改变，需要固定 K 对比。
2. 夜间子集只剩少量被成功跟踪目标，预测误差更低，能否直接说系统夜间更好？参考：不能，可能漏掉了难目标，应一起检查检测和跟踪召回。
3. 写一个只改变一个因素的实验方案，包含输入、对照、指标和失败条件。

- [ ] 能区分四种可靠性量。
- [ ] 能解释覆盖率为何要配合区域大小。
- [ ] 能设计一个可解释的消融实验。
- [ ] 能说明为何要报告样本数和完整链路结果。

**研究时补：**数据不确定性与模型不确定性、开放集识别、分布外检测、复杂概率传播。先用简单基线建立可靠评测。
