# 雷达–视觉融合、跟踪与预测：专业基础学习路线

从**传感器与时空对齐**开始，逐步学习融合感知、多目标跟踪、轨迹预测与实验验证。默认具备基本编程和大学数学基础，专业概念仍配解释、公式和练习；数学或工具知识遇到具体问题时按需补充。

## 1. 四层递进关系

| 层级 | 阶段 | 核心知识 | 阶段产出 |
| --- | --- | --- | --- |
| 第一层：对齐观测 | 01 | 相机成像、雷达测量、内外参、坐标转换、时间同步、自车运动补偿 | 一帧雷达投影和一段序列的对齐说明 |
| 第二层：形成目标表示 | 02–03 | 特征编码、注意力、三维检测、BEV、融合层级 | 输入输出明确的融合感知流程 |
| 第三层：建立运动模型 | 04–05 | 状态空间、卡尔曼滤波、数据关联、轨迹管理、多模态预测 | 检测 → 跟踪 → 预测基线 |
| 第四层：验证与研究 | 06–07 | 不确定性、校准、鲁棒性、消融、论文阅读与复现 | 有对照、指标和失败分析的小实验 |

```text
01 传感器与时空对齐
          ↓
02 模型基础（已熟悉可跳过） → 03 检测与多传感器融合
                                      ↓
                            04 跟踪与状态估计
                                      ↓
                            05 轨迹预测
                                      ↓
                            06 不确定性与实验评估
                                      ↓
                            07 项目实践与论文阅读
```

先统一空间与时间，才能让不同传感器的信息对应；检测形成目标观测后，跟踪维持身份并估计运动；预测利用这些历史状态输出未来；最后通过统一评测检验各环节是否有效。

## 3. 第一阶段具体学什么

按以下顺序进入 01：

1. **传感器测量含义**：相机投影、雷达距离与角度、径向速度及其自车补偿约定。
2. **空间关系**：相机内参、传感器外参、齐次变换、坐标轴和变换方向。
3. **时间关系**：采样频率、时间戳、参考时刻、不同采样时刻的配对。
4. **运动补偿**：历史点如何转到当前参考系，为什么动态目标仍可能拖影。
5. **检查方法**：雷达投影、BEV 可视化及典型错位原因。

完成标准：能解释一条雷达点从原始坐标到图像像素的完整路径，并能指出时间误差、自车运动和目标运动分别会造成什么影响。

## 4. 学习与实践怎样配合

每阶段按“理解物理含义 → 明确公式和假设 → 实现最小例子 → 检查误差”推进。章节中的基础例子用于检查理解，可以按掌握程度跳过。

- **必学**：与模块接口、几何关系、状态模型和评测直接有关的内容。
- **实践时补**：雅可比、数值求解、张量操作等实现所需知识。
- **研究时补**：在线标定、复杂时序融合、开放集识别和联合训练等扩展内容。

传统方法支线：完成 01 后，可以先用人工检测点学习 04–05，形成跟踪与预测的小实验，再回到融合检测。02 作为深度模型知识补充，不必阻塞主线。
