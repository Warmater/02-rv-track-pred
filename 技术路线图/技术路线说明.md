# 雷达–视觉融合目标跟踪与轨迹预测技术路线

本路线依据项目技术文档、README 和论文库整理。当前文件夹为研究规划与文献资料，尚无已实现算法与实验结果；图中的模块均为拟实施路线。主线是：多源数据与评测协议 → 时空对齐与融合感知 → 多目标跟踪与状态估计 → 1–3 秒多模态轨迹预测。长尾场景挖掘与鲁棒性增强贯穿主线，并通过统一评测形成迭代闭环。

## 初学者怎样读这张图

先看每个大框标题下的“回答”，了解该模块要解决的问题；再按“输入 → ①②③④处理步骤 → 输出”的顺序阅读。每个步骤的粗体行说明做什么，下一行说明具体处理方式。框底的“实施层次”区分先建立的基线和后续需要验证的研究改进。

| 图中环节 | 初学者可以这样理解 | 顺序与结果 |
| --- | --- | --- |
| 01 准备数据 | 明确各传感器观测了什么，以及观测发生在何时、何处 | 核对雷达、图像、标定、时间和自车位姿；另备训练与评分所需标注 |
| 02 时空对齐与融合感知 | 将同一目标的观测对齐，再共同判断它的位置和类别 | ①时空对齐 → ②雷达编码、③视觉编码 → ④在统一空间融合检测；两路编码可以分别进行，再汇合 |
| 03 跟踪与状态估计 | 将当前检测接到过去的轨迹，持续认出同一目标 | 每帧执行①运动预测 → ②数据关联 → ③滤波更新 → ④身份维护，输出 ID 和历史状态 |
| 04 多模态预测 | 根据过去的运动，判断未来有哪些可能走法 | 先做①运动外推基线，再扩展②上下文编码 → ③候选轨迹生成 → ④运动可行性检查 |
| 05 长尾与鲁棒性 | 找出在哪些条件下容易出错，并定位原因 | ①收集失败片段 → ②控制变量做退化实验 → ③补充数据或修改模型 |
| 06 统一评测 | 检验结果是否更准，改进是否来自所研究的模块 | 分别评估检测、跟踪、预测和概率质量，再做纯视觉对照及逐项消融 |

**实线**表示主流程与结果传递；**橙色虚线**表示离线分析和实验反馈。下方反馈回路表示根据结果修改相关模块，不表示真实未来可以作为在线预测输入，也不表示只有经历长尾筛选的样本才参加总体评测。

三个核心大框中的编号是模块内部的处理顺序；图最底部的四个框才是项目实施阶段。“多模态预测”指多种未来走法，例如直行、转弯；与雷达、相机这两种传感器模态不是同一含义。

配套学习可从[传感器与时空对齐](../基础知识学习路线/01_传感器与时空对齐.md)开始，再依次阅读融合检测、跟踪与轨迹预测章节。

## 四项研究内容

1. **时空对齐与统一表征**：检查雷达、图像和自车位姿的时间戳及坐标关系，进行自车运动补偿；研究在线外参漂移修正。编码雷达多普勒与 RCS 信息、增强稀疏点云特征，并将视觉特征映射至统一 BEV，用深度不确定性表征视觉几何歧义，形成融合检测与观测质量输出。
2. **检测跟踪与状态估计**：先以运动滤波和显式数据关联形成基线，再研究时序目标查询驱动的检测跟踪联合模型。引入径向速度约束，保持遮挡期间轨迹并在目标重现后接续身份；估计位置、速度、加速度、航向角与横摆角速度，记录状态估计不确定性。
3. **多模态轨迹与置信度预测**：以匀速、匀加速外推作为起点，进一步编码历史状态、目标交互以及可获得的道路几何和可行驶区域约束，输出未来 1–3 秒多条候选轨迹及模式概率。研究上游不确定性的传播，开展概率校准与运动学可行性检验。
4. **长尾场景与鲁棒性验证**：结合模型不确定性、跨模态不一致与轨迹异常度挖掘长尾片段，研究未知目标识别与保守跟踪；覆盖夜间低照度、雨雾、强逆光、隧道出入口、异形与施工目标、遮挡和密集切入。用失败案例指导数据补充和模型迭代。

## 实施阶段与完成标准

| 阶段 | 主要工作 | 阶段产出与完成标准 |
| --- | --- | --- |
| 数据核验与可视化 | 核实模态、连续序列、ID、未来标注、标定和位姿；固定划分与协议 | 图像、雷达投影和 BEV 对照可视化；数据能够支持定义的任务 |
| 模块化基线 | 纯视觉与雷达视觉检测对照；运动滤波、数据关联；匀速/匀加速外推 | 检测→跟踪→预测链路可离线运行并输出统一格式指标 |
| 逐项研究验证 | 多普勒约束、跨帧融合、遮挡恢复、多模态预测、不确定性传播 | 每项改动均有对照或消融，记录成功与失败条件 |
| 联合建模与原型验证 | 在模块化链路基础上研究共享实例表示；长尾挖掘和开放集实验；实车验证 | 可复现原型、消融报告、长尾子集结果和典型失败案例 |

不设未经确认的工期或数值性能目标。在线外参漂移修正、时序查询跟踪、不确定性传播、开放集识别与联合建模均是待验证研究内容。

## 数据与评测边界

- 数据候选来自 README：nuScenes 可用于完整链路探索，但其传统车载雷达不能写成 4D 成像雷达；VoD、TJ4DRadSet、DSERT-RoLL 的可获得模态、连续 ID 和未来标注长度须在选用前核实。实车数据验证是项目技术文档的预期工作，当前文件夹未提供实车数据。
- 雷达径向速度是沿视线方向的分量；完整速度和其他运动状态需要连续观测与模型联合估计。
- 预测实验区分真实历史、模型估计历史、带噪或缺失历史，固定 1–3 秒中的具体预测时长及候选轨迹数 K。道路几何约束须以实际可用数据为前提。
- 观测质量、目标存在性、状态协方差和轨迹模式概率应分别定义；检测分数不能直接视为预测置信度。
- 检测采用数据集适用的官方指标；跟踪关注 AMOTA、身份切换和召回率；预测关注 minADE、minFDE、Miss Rate；概率质量按输出定义采用校准曲线、覆盖率，或在具有相应概率密度模型时采用 NLL。
- 长尾子集应明确场景定义和样本数，报告相对纯视觉基线的变化及适当的置信区间。未知类别实验需预先划定已知/未知类别，难例回流不得污染固定测试集。

## 文献与模块对应

以下映射沿用本地论文库的定位，用于解释研究借鉴关系，不表示已复现或已验证其项目适用性。

| 模块 | 本地文献依据 | 借鉴方向 |
| --- | --- | --- |
| 融合感知 | RCBEVDet、MSSF、MLF-4DRCNet、RaCFormer | BEV 对齐、分层与多阶段融合、目标查询与运动特征 |
| 跟踪与状态估计 | Target Tracking by Cameras and Millimeter-Wave Radars、ADA-Track | 置信度融合、身份关联、时序目标查询；ADA-Track 的雷达接入需另行验证 |
| 轨迹预测 | MTR++、WAKE | 多目标交互、意图查询、历史缺失与物理可行性 |
| 联合建模 | Joint Perception and Prediction 综述、SparseDrive | 接口与误差传递、共享稀疏实例表示；雷达扩展需另行验证 |
